# STM32F103 温度采集&警报系统

基于 STM32F103C8T6 的智能温度监测与警示系统，通过 NTC 热敏电阻采集环境温度，OLED 实时显示，LED 三色指示温度档位。

## 功能概述

- **温度采集**：NTC 热敏电阻（10K, B=3950）+ ADC1 通道1，采集分辨率 12bit
- **温度显示**：0.96寸 OLED（I2C接口），显示 AD 值和温度（精度 0.1℃）
- **温度报警**：三档 LED 指示（绿/黄/红），带迟滞比较防止临界点闪烁
- **滤波算法**：5 次中值滤波，有效抑制噪声干扰

## 温度档位

| 档位 | LED | 温度范围 |
|------|-----|----------|
| 低温 | 绿灯 (LED3) | < 25.5℃ |
| 中温 | 黄灯 (LED2) | 25.5℃ ~ 30.5℃ |
| 高温 | 红灯 (LED1) | > 30.5℃ |

迟滞区间：低温↔中温 1℃，中温↔高温 1℃，避免临界点频繁切换。

## 硬件清单

| 元件 | 型号/规格 | 数量 |
|------|-----------|------|
| 主控芯片 | STM32F103C8T6 | 1 |
| 温度传感器 | NTC 10K B3950 | 1 |
| 显示屏 | 0.96寸 OLED I2C | 1 |
| LED | 红/黄/绿 各1 | 3 |
| 上拉电阻 | 10K | 1 |
| 面包板/洞洞板 | - | 1 |

## 引脚连接

| STM32 引脚 | 功能 | 连接 |
|------------|------|------|
| PA0 | ADC_IN0 | NTC 分压点 |
| PA1 | NC | - |
| PA4 | LED1 | 红灯（低电平点亮） |
| PA5 | LED2 | 黄灯（低电平点亮） |
| PA6 | LED3 | 绿灯（低电平点亮） |
| PB6/PB7 | I2C | OLED SCL/SDA |

详细接线图见 [Wiki 接线图](https://github.com/xinghan-a/stm32-temp-monitor/wiki)

## 软件架构

```
User/
├── main.c              # 主循环：采集→计算→显示→控制
├── LedTempCtrl.c/h     # 温度档位逻辑（迟滞比较）
└── stm32f10x_it.c/h    # 中断服务程序

Hardware/
├── AD.c/h              # ADC初始化 + NTC温度计算 + 中值滤波
├── LED.c/h             # LED控制
├── OLED.c/h            # OLED驱动（I2C）
└── OLED_Font.h         # 字模数据

System/
└── Delay.c/h           # 软件延时

Library/                # STM32标准外设库
Start/                  # 启动文件 + CMSIS核心文件
```

## 编译环境

- **IDE**: Keil MDK-ARM
- **MCU**: STM32F103C8T6
- **库版本**: STM32F10x Standard Peripheral Library v3.5
- **C标准**: C99

## 使用方法

1. 用 Keil 打开 `Project.uvprojx`
2. 编译生成 `.hex` 文件
3. 使用 ST-Link 下载器烧录到 STM32
4. 上电后 OLED 显示温度，LED 根据当前温度亮起对应颜色

## 备注

- NTC 温度计算公式使用 B 值法，精度约 ±0.5℃
- 原代码中有手动修正项 `Temp = Temp - 2.0`，经排查为接线不稳导致，现已去除
- 每 100ms 刷新一次，响应速度适中
