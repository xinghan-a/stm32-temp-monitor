# STM32F103 温度采集&警报系统

基于 STM32F103C8T6 的智能温度监测与警示系统，通过 NTC 热敏电阻采集环境温度，OLED 实时显示，LED 三色指示温度档位。

## 功能概述

- 温度采集：NTC 热敏电阻（10K, B=3950）+ ADC1 通道1，采集分辨率 12bit
- 温度显示：0.96寸 OLED（I2C接口），显示 AD 值和温度（精度 0.1℃）
- 温度报警：三档 LED 指示（绿/黄/红），带迟滞比较防止临界点闪烁
- 滤波算法：5 次中值滤波，有效抑制噪声干扰

## 温度档位

| 档位 | LED | 温度范围 |
|------|-----|----------|
| 低温 | 绿灯 (LED3) | < 25.5℃ |
| 中温 | 黄灯 (LED2) | 25.5℃ ~ 30.5℃ |
| 高温 | 红灯 (LED1) | > 30.5℃ |

迟滞区间：低温↔中温 1℃，中温↔高温 1℃，避免临界点频繁切换。

| 主控芯片 | STM32F103C8T6    | 1 |

| 显示屏 | 0.96寸 OLED I2C    | 1 |
| LED | 红/黄/绿 各1          | 3 |
| 面包板/洞洞板 |             | 1 |

## 引脚连接

| STM32 引脚 | 功能 | 连接 |
|------------|------|------|
| PA0 | ADC_IN0 | NTC 分压点 |
| PA4 | LED1 | 红灯（低电平点亮） |
| PA5 | LED2 | 黄灯（低电平点亮） |
| PA6 | LED3 | 绿灯（低电平点亮） |
| PB6/PB7 | I2C | OLED SCL/SDA |
